# The shared Lambda (SideFrog + QuotaBird)

One function serves sidefrog.com and QuotaBird's four AI pages (Ask QuotaBird, Meeting Prep,
Account Plan, Update Upward), where Arti, the federal sales coach, answers plain questions. Same Function URL, same Gemini 3.5 Flash-Lite settings, no npm packages.

Files (all three go in the zip, at the top level):
- `index.mjs`: SideFrog's handler, v3.8.0. QuotaBird is wired in; SideFrog's own behavior is unchanged.
- `quotabird.mjs`: QuotaBird's request kinds, Arti's prompt and knowledge.
- `quotabird-catalog.mjs`: the tool list. Generated by the site build (`python3 make-tools.py`).
  Redeploy it whenever a tool's fields or questions change.

## Deploy

1. Zip the three files (no folder inside the zip):
   `zip quotabird-lambda.zip index.mjs quotabird.mjs quotabird-catalog.mjs`
2. AWS console → Lambda → the SideFrog function (the one behind
   `https://4s7uc7iyyeh7p4sknfpo6agllq0ahdff.lambda-url.us-east-1.on.aws/`) → Code → Upload from → .zip file.
   Runtime stays Node.js 20 or later, handler stays `index.handler`, timeout stays 30 seconds.
3. Configuration → Environment variables:
   - `ALLOWED_ORIGINS`: add `https://quotabird.com,https://www.quotabird.com` to what's there
     (and your Amplify preview address while you test, e.g. `https://main.xxxx.amplifyapp.com`).
     If this is still `*`, nothing to do yet.
   - Optional: `QB_RATE_LIMIT_PER_MINUTE` (default 10), `QB_RATE_LIMIT_PER_HOUR` (default 60).
   - Optional: `QB_GEMINI_MODEL`, a different model for QuotaBird only (e.g. `gemini-3.5-flash`).
     SideFrog keeps using `GEMINI_MODEL`.
4. Configuration → Function URL → Edit → CORS: add the same origins under Allow origin.
   Allow methods POST (and GET for the health check); allow header `content-type`.
   Leave `SEND_CORS_HEADERS` unset (AWS adds the CORS headers; doubles get rejected).
5. Check it: open the Function URL in a browser. The health check should show
   `"version":"3.8.0"` and `"quotabird":{"version":"1.1.0", ...}`.
6. Use a paid Gemini API key. On the free tier Google may use prompts to improve its products,
   and the QuotaBird pages say the server keeps nothing and the text is handled under the API terms.

Rollback: upload the previous SideFrog zip. QuotaBird's tool pages don't call the Lambda at all,
so only the four AI pages would show "Couldn't connect".

## What the QuotaBird routes do

- `qb_coach` `{ situation, scenario? }` → `{ coach: { high_level_recommendation, coaching_plan: [7 personas], tool } }`.
  Arti, the federal sales coach. `scenario` reruns it with a new variable ("What if…").
- `qb_meeting_prep`, `qb_account_plan` `{ situation }`, `qb_update_upward` `{ situation, type }`: the one-box pages.
- `qb_route`, `qb_explain`: kept for later; no page calls them now.

Nothing typed is logged or stored.
